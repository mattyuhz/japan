# Neighborhood-first experiment

Branch: `codex/neighborhood-first-trial`. Do not merge or publish to the main guide until Matt approves this direction.

The default view starts in Jimbocho with four saved places, selected to mix broad categories. This is deterministic sampling of the existing saves, not researched curation, a ranking, or a verified walking sequence. “See all” expands the neighborhood. The optional map preserves Soft charcoal, clean corners, and Command-scroll zoom.

All saved places remain in a separate archive view. Existing trip logistics remain in Trip plan, with no booking facts changed or reverified. Nearby neighborhood actions return to the top of Explore. Location warnings remain explicit: the underlying neighborhood assignments are still inferred, and all unassigned listings remain available in the archive.

This branch tests whether calmer defaults and separation of planning from exploring improve use. It does not solve location completeness. Before treating it as an on-the-ground guide, verify venue addresses and create genuinely curated neighborhood picks with reasons to visit.

Preview locally with the existing development command. Built files in `docs` are branch-only artifacts; GitHub Pages stays on `main`.

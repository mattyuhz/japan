# Project publishing policy

- The canonical repository is the GitHub `origin` remote (`mattyuhz/Japan`).
- Completed site changes must be pushed to `origin/main`.
- If this site is published, use GitHub Pages or another GitHub-native workflow explicitly approved by Matt.
- Never deploy this project with ChatGPT Sites unless Matt explicitly asks for that exact hosting service.
- Do not recreate `.openai/hosting.json` or push to a Sites-managed Git remote without that explicit request.
